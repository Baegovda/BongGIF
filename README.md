# BongGIF — GIF 녹화·편집기 (Windows)

화면의 원하는 영역을 녹화해 바로 편집하고 GIF / WebP / MP4 / WebM / APNG / AVIF로 저장하는 데스크톱 프로그램입니다.
(Python 3.12 + PySide6 · 소스 MIT)

1.2.0 부터 저장 파이프라인은 형식마다 분리된 인코더입니다. 팔레트는 Pillow median-cut(libimagequant 없음), 영상은 ffmpeg(libx264 / libvpx / libaom)를 서브프로세스로 호출합니다. 컨테이너 관례와 라이선스는 [docs/FORMATS.md](docs/FORMATS.md).

## 1.8.0
현재 버전은 `bonggif/version.py`의 **1.8.0**이고, 공개 태그 **v1.8.0**과 같다.
- 편집 명령 막대의 **전환**(PR #23)에서 두 클립 사이, 또는 앞 구간 끝과 뒤 구간 시작 사이에 전환을 넣는다. 종류는 페이드, 슬라이드, 와이프이다. 슬라이드와 와이프는 새 화면이 들어오는 방향(왼쪽, 오른쪽, 위, 아래)을 고른다. 길이는 밀리초, 프레임 수는 2–60장이다. 미리보기 슬라이더로 중간 장면을 보고, 적용하면 그 프레임이 타임라인에 들어간다. 바로 앞에서 끝나는 클립은 그 프레임을 포함하므로 클립을 이어 저장해도 전환이 한 번 들어간다. 실행취소와 다시실행이 된다. GIF, WebP, MP4, WebM, APNG, AVIF 저장은 타임라인 프레임을 그대로 쓴다.
- 편집 명령 막대의 **줌**(PR #24)에서 구간의 시작 영역과 끝 영역을 정하면, 그 사이로 화면이 확대·이동한다. 이징은 일정, 천천히 시작, 천천히 끝, 부드럽게이다. 미리보기 슬라이더로 중간을 보고, 캔버스 목록에서 시작 영역이나 끝 영역을 고르면 원본 위에 드래그해 사각형을 고친다. 화면 비율은 유지되고 결과 크기는 원본과 같다. 적용하면 그 구간 프레임만 바뀌고, 프레임 수와 지연은 그대로이며 실행취소가 된다. GIF, WebP, MP4, WebM, APNG, AVIF 저장은 바뀐 타임라인을 그대로 쓴다.
- **WebP 클립**(PR #25) 패널은 https://webp-clip.vercel.app/ 와 같은 단계·기본값이다. 이벤트 감도 12 dB, 최소 크기 -45 dB, 볼륨 50%, 원본 FPS, 마스크(모자이크·블러·박스·확대·포탈, 사각형/타원), 떨림 완화와 박스 크기 고정, 구간 목록, 슬로우모션 0.5×, 정지 1.5초, WebP 내보내기(화질 90, 너비 0이면 원본, 무한 반복, 크기에 맞추기).
- **워터마크**(PR #26)는 환경 설정에서 한 번 정한다. 글자 또는 로고 이미지, 위치(모서리·가운데·직접 지정), 투명도, 크기, 켜기/끄기. 미리보기가 그 페이지에 나온다. 켜 두면 GIF, WebP, MP4, WebM, APNG, AVIF 저장과 WebP 클립 내보내기에 자동으로 들어간다. 저장 창의 `이번 저장에 워터마크 넣기`를 끄면 그 파일만 뺀다. 편집 중인 프레임은 바뀌지 않는다.
- 녹화 프레임의 **격자**는 삼등분 또는 N×N이다(PR #27). 켜 둔 값은 다음에 열어도 그대로다. 선은 맞출 때만 보이고 녹화 파일에는 들어가지 않는다. **창 찾기**를 누른 뒤 다른 창 위에 올리면 테두리가 보이고, 클릭하면 녹화 영역이 그 창에 맞는다. 카운트다운·녹화·일시정지에는 창을 옮기거나 크기를 바꾸지 않는다.
- **단축키**(PR #28)는 환경 설정에서 행을 고른 뒤 키를 누르면 바뀐다. 이미 쓰는 키는 들어가지 않고 이유를 보여 준다. 한 항목만, 또는 전체를 기본값으로 되돌릴 수 있다. 저장하면 메뉴 단축키와 녹화 시작·종료 전역 키가 바로 바뀌고, 프로그램을 다시 시작하지 않아도 된다.
- **저장 고급 옵션**(PR #29). WebM은 환경 설정과 저장 창에서 VP8/VP9를 고르고, 알파 채널을 켜면 투명한 픽셀이 파일에 남는다. 끄면 검정 위에 합성한다. APNG 색 모드는 팔레트, RGBA, RGB이다. RGBA는 원본 알파를 유지하고, RGB는 알파 없이 저장하며, 색 수는 팔레트일 때만 쓴다. **색 유지**를 켜면 GIF는 고른 팔레트와 디더를 색 수 축소 없이 쓰고(저장 창에서 켜면 256색·디더 없음으로 맞춘다), WebP·APNG는 무손실, WebM·MP4·AVIF는 무손실에 가깝게 저장한다. 설정과 저장 창은 같은 값을 쓴다.

## 실행
```bat
build_exe.bat          :: venv 생성 → 의존성+PyInstaller 설치 → dist\BongGIF\BongGIF.exe 빌드
```
실행하면 **하나의 메인 창**이 열립니다. 상단 탭: `홈` · `녹화` · `편집` · `관리` (어두운 테마, 자체 제작 아이콘).
영상 바로 열기: `gif_converter.bat [영상파일]` 또는 `python BongGIF.py [영상파일]`

### 메뉴 / 단축키
- 파일: 열기(영상/GIF) `Ctrl+O`, 이미지 시퀀스, 영상 열기 `Ctrl+G`, 저장 `Ctrl+S`, 끝내기 `Ctrl+Q`
- 편집: 실행취소 `Ctrl+Z`, 다시실행 `Ctrl+Y`, 프레임 삭제 `Delete`, 재생/정지 `Space`
- 편집(구간): 현재 프레임을 시작 `I` / 끝 `O`, 구간만 남기기 `Ctrl+K`
- 편집(프레임): 구간 자르기 `Ctrl+T`, 10% 빠르게/느리게 `Ctrl+↑/↓`, 처음/이전/다음/끝 `Home/←/→/End`, 확대/축소/맞춤 `Ctrl+=/-/0`
- 파일: 이미지 가져오기 `Ctrl+I`
- 도구: 화면 녹화 `Ctrl+R`, 관리 `Ctrl+M`, 환경 설정 `Ctrl+,`, 작업 취소 `Esc`
- 클립 `A`, 추적 `T` / `Shift+T`, 슬로모 `S`, 프레임 유지 `P`, 내보내기 `Ctrl+E`, 단축키 `F1`
- 도움말: 로그 폴더 열기, 정보

### 진행률 · 응답성
- 불러오기, 영상 정보 읽기, 프레임 추출, 썸네일, 자르기/크기/텍스트/스티커/흑백 등 여러 프레임 편집, 저장(목표 용량 각 시도 포함),
  HQ 팔레트 생성/적용이 모두 **백그라운드 스레드**에서 실행됩니다. 창이 '응답 없음'으로 멈추지 않습니다. 여러 파일을 한꺼번에 바꾸던 일괄 변환은 1.3.0에서 빼었습니다.
- 상태바에 현재 단계(예: `프레임 추출 중 42/86`, `목표 용량 시도 3/7: 1320px 12색 — …`, `팔레트 생성 중`)와 % 진행 막대, **취소** 버튼이 표시되고,
  작업 중에는 충돌하는 메뉴/버튼이 비활성화됩니다. 변환기의 HQ 경로(`converter._run_ffmpeg_progress`)만 ffmpeg `-progress pipe:1`의 frame 값으로 진행률을 계산합니다. 편집기 저장은 프레임마다 `ctx.step`입니다.
- 썸네일은 96×72로 작게, 현재 프레임 근처부터 백그라운드에서 생성됩니다. 4K 프레임 미리보기는 축소본으로 표시합니다.

### 저장
- `저장`(Ctrl+S) → **저장 설정**(형식 GIF/WebP/MP4/WebM/APNG/AVIF, GIF 인코더 Pillow/HQ ffmpeg, 팔레트, 색상 수, 디더링, 목표 용량 MB·최대 시도) →
  파일 대화상자(기본 폴더: 마지막 저장 폴더, 없으면 원본 폴더 / 기본 이름: 원본 파일 이름).
- 저장이 끝나면 경로·최종 용량을 알려주고 `폴더 열기`(Windows: 탐색기에서 파일 선택) / `파일 열기` 버튼을 제공합니다.

### 로그
- `%LOCALAPPDATA%\BongGIF\logs\bonggif.log` (Linux: `~/.local/share/BongGIF/logs`), 2MB×5개 회전.
  작업 시작/완료/소요 시간/예외를 기록하며, 처리되지 않은 예외는 로그 + 오류 대화상자로 표시합니다. `도움말 > 로그 폴더 열기`.

개발 실행: `python -m venv .venv && .venv\Scripts\pip install -r requirements.txt && .venv\Scripts\python BongGIF.py [파일]`

## 녹화
- 항상 위인 반투명 프레임 창. 중앙의 투명 영역만 캡처하고, 제목 막대·도구 막대·테두리는 캡처되지 않습니다.
- 제목 막대, 하단 도구 막대, 바깥 테두리를 끌어 이동합니다. 점 손잡이가 있습니다. 방향키는 1px, Shift+방향키는 10px입니다(너비·높이 칸에 포커스가 있으면 그 숫자를 바꿉니다).
- 모서리 4개와 변 중앙 손잡이 4개로 크기를 조절합니다. 히트 영역은 10px 이상이고 커서가 방향에 맞게 바뀝니다. 현재 크기는 가로×세로로 실시간 표시됩니다. 너비·높이를 입력하거나 프리셋(320×240 ~ 1920×1080)을 고릅니다. 화면 가장자리와 다른 창 가장자리에 붙습니다.
- 카운트다운·녹화·일시정지 동안에는 위치와 크기가 고정되고 제목에 `위치 고정`이 보입니다. 정지하면 다시 옮길 수 있습니다.
- 캡처 창의 FPS는 5~30, 카운트다운 0~10초입니다. 녹화 탭의 FPS 스핀은 1~60이고, 그 크기 목록은 1280×720까지입니다(1920×1080은 캡처 창 프리셋에만 있습니다). 녹화/일시정지/정지, **F9** 시작·종료(창 포커스 시; `keyboard` 설치 시 전역), Esc 닫기. `dxcam`은 선택 import이며 `requirements.txt`에 없습니다.
- 15fps 지연은 66, 67, 67ms 입니다(3프레임 = 200ms, GIF에서는 6센티초와 7센티초). 같은 화면이 이어지면 프레임을 합치고 시간만 더합니다(설정에서 끌 수 있음).
- 마우스 커서 표시 옵션, 실제 경과시간으로 프레임 지연 기록, 고DPI 보정
- 캡처: `mss` → (선택) `dxcam` → Qt 화면 캡처 순으로 폴백

## 오류 자동 보고
- 예기치 않은 오류가 나면 익명화된 오류 정보(버전·OS·오류 내용·로그 일부)를 자동으로 보냅니다. 사용자 경로·이름은 지워집니다. 오프라인이면 저장했다가 나중에 보냅니다.
- `환경 설정 > 일반 > 오류 자동 보고`(기본 켜짐)로 끌 수 있습니다. 중계 서버 설정은 `relay/README.md` 참고.
- **자체 업데이트(설치된 exe에서만)**: `*-win64.zip`을 진행률·취소와 함께 받고, 크기와 SHA256(`.sha256` 파일)을 검증한 뒤 `%LOCALAPPDATA%\BongGIF\update\staging`에 풉니다.
  재시작하면 업데이트 스크립트가 프로그램 종료를 기다렸다가 설치 폴더를 `<설치폴더>.bak`으로 백업하고 새 파일로 바꾼 뒤 BongGIF를 다시 실행합니다. 실패하면 백업으로 되돌립니다.
  기록은 `logs\update.log`에 남습니다. 설치 폴더에 쓰기 권한이 없으면(예: Program Files) 안내만 표시하므로, 사용자 폴더에 압축을 푸는 것을 권장합니다.
- 소스(`python BongGIF.py`)로 실행 중이면 릴리스 페이지를 엽니다.

## 릴리스 (GitHub Actions)
`v*` 태그를 푸시하면 `.github/workflows/release.yml`이 windows-latest + Python 3.12에서 PyInstaller(onedir)로 빌드하고
`BongGIF-<태그>-win64.zip`과 `.sha256`을 GitHub Release에 올립니다. 릴리스는 이 태그 푸시로 만들어집니다. 태그는 `bonggif/version.py`의 버전과 같아야 합니다(다르면 실패). 라이선스: MIT (`LICENSE`).
PR은 주인이 명시적으로 승낙한 뒤에만 머지합니다. 주인과의 대화는 한국어입니다. 참조 앱을 분석해도 된다는 제작사 허락이 있습니다. 그 앱의 이름은 저장소에 쓰지 않고, 에셋과 코드는 복사하지 않습니다. 분석 산출물은 주인 PC의 Desktop 폴더에만 두고 커밋하지 않습니다. 배포 exe는 언팩하지 않았고, 라이선스·체험판·서명 검사는 분석하지 않았습니다.

## 열기 / 저장
- 열기: GIF, WebP, APNG, MP4/MOV/AVI/MKV/WebM, 이미지 시퀀스(PNG/JPG/BMP 여러 장)
- 저장: GIF(GIF89a, NETSCAPE 루프, 주석 `BongGIF 버전 (시각); q=N`, 적응 로컬 팔레트, 같은 픽셀 투명, 변경 영역만), WebP(VP8X+EXIF, ANIM 루프, ANMF, 품질 0–100), APNG(팔레트, Software 텍스트, OVER 블렌드), MP4(H.264 High, 홀수 변은 패딩 없이 크롭, 소리 없음), WebM(VP8, 타임코드 1ms), AVIF(avis, 품질 70 이상 YUV 4:4:4, 무한 반복). 자세한 표는 [docs/FORMATS.md](docs/FORMATS.md).

## 영상 → GIF (편집기에 바로 열기)
- 영상(MP4/MOV/AVI/MKV/WebM)·GIF·WebP를 **창/캔버스/타임라인에 끌어다 놓거나** `Ctrl+O`로 열면 곧바로 편집기 프레임으로 들어옵니다.
  첫 프레임이 즉시 보이고, 나머지는 백그라운드에서 디코딩되며 썸네일이 도착하는 대로 채워집니다(상태바 `영상 디코딩 중 n/N`, %, 취소 — 취소 시 그때까지의 프레임 유지).
- 기본 편집용 설정: fps는 원본(최대 30), 너비 최대 1280px. 4K 등 축소해서 불러오면 캔버스 위 안내 막대에
  `원본 해상도로 다시 불러오기` / `불러오기 옵션…`(FPS·작업 해상도·시작/끝 시간) 버튼이 나타납니다.
- 예상 메모리가 3GB를 넘으면 불러오기 옵션을 먼저 띄워 시간 범위나 FPS·해상도를 줄이도록 안내합니다.
- 구간 자르기는 편집기에서: `프레임` 탭의 **구간 자르기**(시작/끝, `I`/`O`로 현재 프레임 지정, `Ctrl+K` 구간만 남기기, 현재 이전/이후 삭제),
  타임라인에서 여러 프레임을 선택하면 구간이 자동 지정되고, 타임라인 우클릭 메뉴에도 같은 기능이 있습니다. 모두 `Ctrl+Z`로 되돌릴 수 있습니다.
- 속도·크기·자르기·텍스트는 편집기 도구로, 저장은 `저장`(형식·품질·목표 용량) 하나로 합니다.
- 여러 파일을 한 번에 바꾸는 일괄 변환은 1.3.0에서 빼었습니다. 영상 하나는 열기로 편집합니다.
- ffmpeg 시킹은 `-ss`(입력 앞), rawvideo 파이프 스트리밍, HQ는 palettegen→paletteuse 2패스. subprocess는 인자 리스트로만 호출(공백·한글 경로 안전).
